# Memórias de Uauá VR

Museu imersivo WebXR feito com A-Frame. Toda a cenografia é criada por geometria, luz, materiais e texto em tempo real, sem imagens ou texturas.

## Executar

```bash
npm install
npm run dev
```

Abra `http://localhost:4173` no computador ou celular. Em um navegador compatível com WebXR, use **Entrar em VR**.

O visitante permanece no centro da sala. Mouse, toque, movimento do aparelho ou headset controlam apenas o olhar; o deslocamento está desativado.
